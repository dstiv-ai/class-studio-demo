# Class Studio — interactive portfolio demo

Open https://dstiv-ai.github.io/class-studio-demo/ and try the two-minute walkthrough. No account is needed.

A proof of concept for teacher-controlled research, assessment across lessons, a question-led tutor and deliberate feedback release. All learners, work and marks are fictional examples. Tutor replies are scripted locally. There are no backend connections or live AI calls.

Designed and built by Dimitrios Stivaktas.

This repository contains the static build only. The application source and credentials are not included.
